# Cascavel
A Snake clone made using GNOME technologies.
</td></tr></table>

## Features

- Local two-player multiplayer.
- Three board sizes: Small (16×16, default), Medium (32×32) and Large (64×64).
- Adjustable game speed.
- Randomly generated walls obstacles.
- Gesture controls.
